# Overview

The `kernels` CLI provides commands for managing compute kernels.

## Commands

| Command                                     | Description                        |
| ------------------------------------------- | ---------------------------------- |
| [benchmark](cli-benchmark)               | Run benchmark results for a kernel |
| [cache ls](cli-cache)                    | List cached kernels and build variants |
| [download](cli-download)                 | Download a kernel                  |
| [describe-api](cli-describe-api)         | List public functions and layers   |
| [info](cli-info)                         | Describe a kernel                  |
| [lock](cli-lock)                         | Lock kernel revisions              |
| [verify-signature](cli-verify-signature) | Verify a kernel signature          |
| [variants](cli-variants)                 | Show variants and compatibility               |
