# 实验性的

该目录包含一个最小的、清晰分隔的空间，用于快速迭代新想法。

> [!警告]
> **稳定性合同：** `trl.experimental` 下的任何内容都可能在*任何*版本（包括补丁版本）中更改或删除，而无需事先弃用。不要依赖这些 API 来处理生产工作负载。

## 晋升途径（简单）

1. **主存储库之外的原型：** 在您自己的分支或单独的存储库中开始开发以快速迭代。
2. **实验性包容：** 一旦为早期用户做好准备，就将想法转移到`trl.experimental.<feature>`。
3. **改进：** 添加测试、简短的文档/示例，并演示用法。
4. **推广：** 一旦 API 证明稳定并且社区有明确的兴趣或采用，请将其移至 `trl.<feature>`（稳定模块）。

## 常见问题解答

**为什么不直接使用分支？**
因为分支不发货给用户；包内的实验代码可以让早期采用者尝试并提供反馈。

**这些 API 会在没有警告的情况下更改或消失吗？**
是的。 `trl.experimental` 中的任何内容都可以在*任何*版本中更改或消失。

**我应该在生产中使用它吗？**
仅当您愿意在情况发生变化时快速更新代码时。**维护人员会及时修复`trl.experimental`中的问题吗？**
不一定。实验模块是新想法的游乐场，维护人员可能不会优先考虑那里的错误修复或功能请求。在（或除非）该功能升级为稳定的 API 之前，问题可能仍未得到解决。

**如何使运行时通知静音？**

使用：`export TRL_EXPERIMENTAL_SILENCE=1`。
