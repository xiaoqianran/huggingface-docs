# 空格

[Hugging Face Spaces](https://huggingface.co/spaces) 提供了一种直接在您的个人资料或组织的个人资料上托管 ML 演示应用程序的简单方法。这使您可以创建 ML 组合，在会议上或向利益相关者展示您的项目，并与 ML 生态系统中的其他人协作。

我们内置了对很棒的 SDK 的支持，让您可以在几分钟内用 Python 构建很酷的应用程序：**[Gradio](https://gradio.app/)**，但您也可以释放 Docker 的全部功能并托管任意 Dockerfile。最后，您可以使用 JavaScript 和 HTML 创建静态空间。

您还可以升级您的空间以运行[on a GPU or other accelerated hardware](./spaces-gpus)。 ⚡️
