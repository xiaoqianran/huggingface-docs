# 网络安全

> [!警告]
> 此功能是 Enterprise Plus 计划的一部分。

## 定义您的组织 IP 范围

您可以列出组织出站流量的 IP 地址，以申请更高的速率限制和/或强制从公司网络对 Hugging Face 进行经过身份验证的访问。
出站 IP 地址范围以 CIDR 格式定义。例如，`52.219.168.0/24`或`2600:1f69:7400::/40`。

您可以设置多个范围，每行一个。 

一旦组织管理员在网络安全设置中填充“组织 IP 范围”，则需要由 Hugging Face 解决方案工程师和组织管理员联合执行手动验证，“需要 IP 范围内的用户登录”设置才可用。手动验证“组织 IP 范围”并且组织管理员启用“仅限制组织访问您的 IP 范围”和“要求您 IP 范围内的用户登录”后，将应用以下流程：
- 当用户到达平台时，他们的 IP 地址将被检查。
- 如果 IP 位于组织定义的范围内，则用户必须进行身份验证（通过组织的 SSO（如果启用））。
- 经过身份验证后，内容访问策略将确定用户可以访问哪些资源。

## 更高的集线器速率限制

Hub 上的大多数操作都有限制；例如，用户每天只能创建一定数量的存储库。 Enterprise Plus 自动为您的用户的每项操作提供可能的最高速率限制。

此外，一旦设置了 IP 范围，启用“更高的 Hub 速率限制”选项可以让您的组织受益于 Hub API 上的最高 HTTP 速率限制，从而解锁大量模型或数据集下载。

有关速率限制的更多信息，请参阅 [Hub Rate limits](./rate-limits) 文档。

## 限制组织仅访问您的 IP 范围此选项将对您组织的资源的访问权限限制为仅来自您定义的 IP 范围的资源。任何人都无法访问您的 IP 范围之外的组织资源。这些规则也适用于访问令牌。启用后，此选项将解锁下面的其他嵌套安全设置。

### 要求您的 IP 范围内的用户登录

启用此选项后，从公司网络访问 Hugging Face 的任何人都必须登录并属于您的组织（IP 范围更改时需要手动验证）。如果启用，您可以选择定义内容访问策略。

### 内容访问政策 

通过阻止 Hugging Face Hub 的特定内容来定义细粒度的内容访问策略。 

例如，您可以阻止组织的成员访问空间。当您组织的用户导航到被阻止的内容时，他们将看到以下页面：要定义阻止的内容，请添加针对存储库类型、组织、特定存储库或组合（例如给定组织内的存储库类型（例如来自特定组织的所有空间））的规则。

始终允许字段允许您定义阻止规则的例外情况。您可以定位即使在应用阻止规则时也应保持可访问的内容。

#### 保持存储库元数据可见

默认情况下，当内容访问策略阻止存储库时，整个存储库将无法访问。启用“保持存储库元数据可见”选项仅阻止存储库的内容，同时保持其元数据可见。

启用此选项后，被阻止的存储库仍会显示其元数据（存储库卡、配置文件和列表页面），并且仅阻止其内容：文件下载、数据集查看器、运行空间和模型推理。
