# 用户研究
## 模型卡受众和用例

在我们对模型文档工具（数据卡等）的调查过程中，我们注意到不同的利益相关者如何利用现有的基础设施来创建一种模型卡，其中的信息集中于他们所需的领域。

其中一个例子是“业务分析师”或那些关注 B2B 的人员以及仅限内部的受众。针对该受众的静态且更多手动方法是使用 Confluence 页面。 （*如果 PM 编写页面，我们会将模型创建者与其理论消耗分离；如果 ML 工程师编写页面，他们可能倾向于只强调某种类型的信息。* [^1]）或建议组合 HTML (Jinja) 模板、Metaflow 类和外部 APi 密钥，以便创建包含其领域/用例所需的模型信息视角的模型卡。 

我们进行了一项用户研究，目的是验证基于文献的模型卡结构，并了解不同利益相关者观点的重要性排名的部分/领域。该研究旨在验证以下组成部分：

* **模型卡布局**在我们对模型卡的最新技术进行检查时，我们注意到中心上拥有模型卡的前 100 个下载模型中的重复部分。根据此分析，我们对顶部重复出现的模型卡部分和重复出现的信息进行了编目，这与 Bloom 模型卡的结构相结合，使我们得到了标准模型卡结构的初始版本。 

当我们开始构建用户研究时，使用了 [initial model card structure](./model-card-annotated) 的两种模型卡变体用作交互式演示。这些演示的目的不仅是为了了解用户对模型卡视觉元素的不同看法，还为了了解向用户呈现的内容。 {期望的}结果将使我们能够进一步了解是什么使模型卡更易于阅读，仍然在模型卡内提供一定程度的交互性，同时以易于理解的[平易近人]的方式呈现信息。

* **利益相关者的观点**由于具有不同技术背景的不同人可以在模型和随后的模型卡上进行协作，因此我们试图验证不同利益相关者观点的需求。基于编写不同型号卡部分和首先阅读的部分的易用性

参与者从阅读模型卡的角度以及作为模型卡的作者的角度对模型卡的不同部分进行排名。排序方案（1 是最高权重，10 是最低权重）应用于用户通常在模型卡中首先阅读的不同部分以及模型卡作者认为最容易编写的模型卡部分。 

## 用户研究调查回复摘要

我们的用户研究进一步明确了不同用户配置文件/利益相关者会发现更具挑战性或更容易编写的部分。下图所示的结果显示，虽然“偏见、风险和限制”部分在“您以什么顺序编写模型卡”和“您首先看什么部分”方面分别在模型卡编写者和模型卡阅读器中排名第二，但它也被认为是最具挑战性/最长的部分。这支持/认可需要进一步评估偏见、风险和局限性部分，以协助编写这一决定性/势在必行的部分。

然后，使用这些模板为下载次数最多的 200 个 Hugging Face (HF) 模型生成模型卡。 

* 我们首先将所有 Hugging Face 模型拉到中心，特别是有关限制和偏差的小节（“风险”小节基本上不存在）。
* 根据最连续使用且模型下载次数较多的输入，并按模型类型进行分组，该工具在偏差、风险和限制部分中提供提示文本。如果未指定模型类型，我们还会提示默认文本。使用这些信息，我们返回到对中心上所有模型卡的分析，结合其他研究人员和 HF 同行的建议，以及对我们可以在用户创建模型卡时提供给用户的提示信息类型的额外研究。这些默认的提示文本使我们能够满足目标：

1) 对于以前没有创建过模型卡或通常不为其模型制作模型卡或任何其他类型的模型文档的用户，提示文本使这些用户能够轻松创建模型卡。这反过来又增加了创建的模型卡的数量。
   
2) 已经编写了模型卡的用户，提示文本邀请他们向模型卡添加更多内容，进一步开发模型卡的内容/标准。

### 对特定型号卡格式的反馈

#### 格式 1： 
**集线器上的当前[distilbert/distilgpt2 model card](https://huggingface.co/distilbert/distilgpt2)**

**见解：**

* 受访者认为该模型卡格式简洁、完整且可读。 
* 对于可折叠部分没有达成共识（有些人喜欢它们并想要更多，有些人不喜欢它们）。 
* 一些受访者表示“风险和限制”应与“超出范围的使用”并列

#### 格式 2： 
**Nazneen Rajani 的 [Interactive Model Card space](https://huggingface.co/spaces/nazneen/interactive-model-cards)**

**见解：**

* 虽然少数受访者确实喜欢这种格式，但大多数人发现它令人难以承受或信息过多。一些人认为这可能是一个很好的工具，可以为更高级的受众分层到基本模型卡上。#### 格式 3： 
**Ezi Ozoani 的 [Semi-Interactive Model Card Space](https://huggingface.co/spaces/Ezi/ModelCardsAnalysis)**

**见解：**

* 一些受访者认为这种格式令人难以接受，但他们普遍认为它不如格式 2 令人难以接受。
* 一些受访者不同意当前的布局，并就每列中应优先考虑哪些部分提供了具体反馈。

### 部分排名
*根据平均排名排序。箭头的显示相对于调查问题中相关部分的顺序。*

**见解：** 
* 在编写模型卡时，受访者普遍表示他们会按照调查问题中列出的部分的顺序编写模型卡。
* 当按书写的难易程度/速度对模型卡的各个部分进行排名时，一致认为有关用途、限制和风险的部分是最困难的。
* 在阅读模型卡片时，受访者表示，他们查看卡片各部分的顺序与调查问题中列出各部分的顺序接近（但并不完全一致）。
