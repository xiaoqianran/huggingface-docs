# 在空间中使用 OpenCV

为了在您的 Gradio 或 Python 空间中使用 OpenCV，您需要让空间安装 Python 和 Debian 依赖项

这意味着将 `python3-opencv` 添加到 `packages.txt` 文件，并将 `opencv-python` 添加到 `requirements.txt` 文件。如果这些文件不存在，您需要创建它们。 

看一个例子，[see this Gradio project](https://huggingface.co/spaces/templates/gradio_opencv/tree/main)。
