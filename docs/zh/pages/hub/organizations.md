# 组织

Hugging Face Hub 提供**组织**，可用于对帐户进行分组并管理数据集、模型和空间。该中心还允许管理员将用户角色设置为 [**control access to repositories**](./organizations-security) 并管理其组织的 [payment method and billing info](https://huggingface.co/pricing)。

如果组织由于许可或隐私问题需要跟踪用户对数据集或模型的访问，则组织可以启用 [user access requests](./datasets-gated)。

注意：使用组织设置中的上下文切换器可在您的帐户和组织之间快速切换。
