# 高级计算选项

> [!警告]
> 此功能是团队和企业计划的一部分。

团队和企业组织可以获得高级计算选项，以加速他们的机器学习之旅。

## 在您的组织中托管 ZeroGPU 空间

ZeroGPU 是一种动态 GPU 分配系统，可优化 Hugging Face Spaces 上的 AI 部署。通过根据需要自动分配和释放 NVIDIA RTX Pro 6000 Blackwell GPU (96GB VRAM)，组织可以高效地为其 AI 应用程序提供服务，而无需专用 GPU 实例。

**对组织的主要好处**

- **免费 GPU 访问**：通过动态分配，无需额外费用即可访问强大的 NVIDIA RTX Pro 6000 Blackwell GPU
- **增强的资源管理**：托管多达 50 个 ZeroGPU 空间，以实现团队范围内的高效 AI 部署
- **简化部署**：与基于 PyTorch 的模型、Gradio 应用程序和其他 Hugging Face 库轻松集成
- **企业级基础设施**：访问高性能 NVIDIA RTX Pro 6000 Blackwell GPU，每个工作负载高达 96GB VRAM
