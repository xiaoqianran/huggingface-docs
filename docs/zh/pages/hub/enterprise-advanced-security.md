# 高级安全性

> [!警告]
> 此功能是团队和企业计划的一部分。

团队和企业组织可以通过针对成员和存储库的高级安全控制来提高其安全性。

    
    

## 会员安全

配置其他安全设置来保护您的组织：

- **双因素身份验证 (2FA)**：要求所有组织成员启用 2FA 以增强帐户安全性。
- **用户批准**：对于具有已验证域名的组织，需要管理员批准具有匹配电子邮件地址的新用户。这会将经过验证的徽章添加到您的组织页面。
- **隐藏成员列表**：启用后，成员列表将在组织页面上不可见。请注意，用户可能会通过其他方式找到组织成员资格信息，因此请勿用于关键用例。

## 存储库可见性控制

管理组织中存储库的默认可见性：- **默认公开**：创建具有公共可见性的新存储库
- **默认情况下私有**：创建具有私有可见性的新存储库。请注意，更改此设置不会影响现有存储库。
- **仅限私有**：对所有新存储库强制实施私有可见性，只有组织管理员才能更改可见性设置

这些设置可帮助组织保持对其所有权的控制，同时在需要时启用协作。
