# 搜索

您可以使用**全文搜索**轻松搜索中心上的任何内容。我们索引模型卡、数据集卡和 Spaces app.py 文件。

直接访问 https://huggingface.co/search，或者使用 https://huggingface.co 顶部的搜索栏，您可以选择“尝试全文搜索”，以帮助您在 Hub 上跨模型、数据集和空间查找所需内容：

## 轻松过滤

默认情况下，当用户输入查询时，将搜索模型、数据集和空间。如果愿意，可以进行过滤以仅搜索模型、数据集或空间。

此外，可以从浏览器地址栏中复制并共享 URL，其中应包含过滤器信息作为 URL 查询。例如，当使用仅显示 `Spaces` 的过滤器搜索查询 `llama` 时，会得到 URL https://huggingface.co/search/full-text?q=llama&type=space
