# 适度

> [!提示]
> 查看 [Code of Conduct](https://huggingface.co/code-of-conduct) 和 [Content Guidelines](https://huggingface.co/content-guidelines)。

## 报告存储库

要报告存储库，您可以单击存储库右上角的三个点。之后，您可以单击“报告存储库”。这将使您能够解释报告背后的原因（道德问题、法律问题、不起作用或其他）以及报告的说明。完成此操作后，将开始**公开讨论**。

## 报告评论

要举报评论，请单击评论右上角的三个点，然后选择“举报”。将出现一个模式，您可以在其中描述举报的原因 - 这将由 Hugging Face 审核团队进行审核。

提交报告时，您还可以选择同时**阻止评论作者**。您还可以直接从评论菜单阻止用户，而无需提交报告 - 请参阅下面的[Blocking a user](#blocking-a-user)。

## 阻止用户

阻止用户会阻止他们与您的存储库和其他 Hub 内容进行交互。当您阻止某人时，您与该用户之间的任何现有关注关系也会被删除。

有两种方法可以阻止用户发表讨论评论：- **从报告模式** — 从评论的菜单中选择“报告”，填写您的原因，然后在提交之前选中 **“是，阻止此用户”**。如果您还想向 Hugging Face 审核团队报告评论，请使用此选项。 
- **直接从评论菜单** — 单击其他人撰写的评论右上角的三个点，然后选择 **“阻止@用户名”**。在应用阻止之前，系统会要求您确认。

> [!注意]
> 您的帐户中必须有经过确认的电子邮件地址才能阻止用户。
