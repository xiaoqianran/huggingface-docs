# 预发布模型页面

> [!警告]
> 此功能适用于企业计划或更高版本的组织 - 或联系我们。

预发布模型页面可让您的组织在仍处于私有状态时宣布即将推出的模型。访问者看到的不是 404 页面，而是一个专门的公告页面，其中包含发布日期的实时倒计时和**发布时点赞和通知**按钮，因此他们可以在模型发布时通过电子邮件收到通知。当您公开模型时，它被视为已发布，并且公告页面将替换为模型卡。

## 资格

- 您的组织必须订阅 [Enterprise](https://huggingface.co/enterprise) 计划或以上计划。
- 模型存储库必须位于 **组织命名空间** 下（例如 `my-org/my-upcoming-model`）。用户拥有的存储库不符合资格。
- 模型存储库必须是**私有**。将模型公开发布（参见[below](#notify-your-subscribers-on-release)）。

## 公布你的型号

要将 **私有** 模型页面转换为预发布页面，请将 `release_date` 字段添加到模型卡元数据（存储库 `README.md` 顶部的 YAML 部分）：

```yaml
---
release_date: 2026-07-27
description: "A short tagline shown on the pre-release page"
---
```

如果您想定位特定时间，则 `release_date` 字段接受 YAML 日期或引用的 ISO 8601 时间戳：

```yaml
release_date: "2026-07-27T15:00:00Z"
```无效值会被元数据验证器拒绝并忽略。该日期不必是将来的日期：对于过去的日期，页面会显示“即将推出”而不是倒计时。日期以 UTC 格式显示。

一些可选的元数据字段可让您自定义预发布页面：

|领域 |效果|
| --- | --- |
| `description` |预发布页面的英雄标语，也用作页面的元描述。 |
| `pretty_name` |显示人类可读的名称，而不是英雄标题中的存储库名称。 |
| `approximate_eta` |如果 `release_date` 只是估计值，则设置为 `true`：然后用 **当前预计到达时间** 徽章标记日期。 |
| `thumbnail` |自定义社交共享图像的 URL，替换生成的图像。 |

```yaml
---
release_date: 2026-07-27
approximate_eta: true
pretty_name: "My Upcoming Model"
description: "A short tagline shown on the pre-release page"
---
```

还有一些事情需要了解：

- 模型卡的 Markdown 正文（YAML 元数据下方的所有内容）是访问者在预发布页面上阅读的内容 - 用它来描述即将发生的内容、显示预告片、论文链接等。
- 您还不需要上传任何权重：在整个公告期间，存储库只需要`README.md`。准备好后即可上传模型文件。
- 编辑模型卡元数据后，预发布页面可能需要一些时间才能打开或关闭。## 访客看到的内容

虽然模型是私有的并且设置了`release_date`（并且您的组织符合资格），但访问者会看到预发布页面而不是 404 页面：

- 英雄带有**即将发布**标签、模特名称、您的口号以及发布日期的实时**倒计时**。英雄的颜色源自您组织的头像。
- **发布时点赞和通知**按钮：单击它会点赞该存储库，并向用户订阅该发布的电子邮件通知。用户需要登录，不喜欢该模型则需要取消订阅。
- 模型卡内容。
- 侧边栏显示点赞数（当用户**等待发布**时）以及最近的点赞者、预计发布日期以及您组织的最新型号。
- 专用的社交分享缩略图，使用与英雄相同的颜色。

    
    

> [!提示]
> 预发布页面呈现您的模型卡内容 - 您在 `README.md` 正文中编写的所有内容在公告发布时都是公开可见的，包括它引用的图像和视频。存储库的其余部分保持私有：文件、讨论和 API 访问仍然仅限于成员，并且模型不会公开列出。当倒计时达到零时，页面会显示 **“即将推出”** — 预发布页面将保持打开状态，直到您公开模型。

## 会员看到的内容

对存储库具有**读取访问权限**的每个人都会看到常规模型页面，因此您的团队可以在公告发布时继续管理文件和设置：

- 模型页面上的横幅表明该模型处于预发布状态。单击 **预览页面** - 或将 `?preview` 附加到模型 URL - 以检查访问者看到的内容。
- 在模型列表中，模型显示有 **预发布** 徽章。

    
    

## 发布时通知您的订阅者

当您准备好发布时：

1. 将模型文件推送到存储库。
2. 使模型**公开**。这会发布模型：预发布页面变成常规模型页面 - 无需删除 `release_date` 字段。
3. 具有写入权限的 Repo 成员将看到一条横幅，上面写着“N 个用户正在等待有关此版本的通知”，并带有 **发送版本通知** 按钮。
4. 单击 **发送发布通知**，通过电子邮件向每个订阅者发送您的模型现已在 Hugging Face 上提供的信息。当模型公开时，通知不会自动发送：您可以选择何时发送通知。有几件事需要知道：

- 订阅者是在模型预发布时喜欢该模型的用户，因此横幅中的数量可能低于喜欢的总数。
- 每个订阅者最多会收到一次电子邮件，通知发送后横幅就会消失。
- 通知尊重每个用户的[notification preferences](https://huggingface.co/settings/notifications)（“您订阅的版本可用”）。

## 注意事项

- **该页面在日期之后保持在线状态**：到达发布日期不会自动将预发布页面关闭；将模型公开以发布它并切换回常规模型页面。
- **公开模型即发布**：只有模型公开后才能发送发布通知。
- **在模型仍处于私有状态时删除 `release_date`** 会导致预发布页面下降：访问者会再次获得 404 页面，就像任何私有模型一样。
- **再次将模型设为私有**（当`release_date`仍然设置时）会重新打开预发布页面。
