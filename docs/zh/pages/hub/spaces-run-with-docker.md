# 使用 Docker 运行

您可以使用 Docker 在本地运行大多数 Space。
要查看下载和运行 Spaces 的 Docker 映像的说明，请单击 Space 页面右上角的“使用 Docker 运行”按钮：

	
	

## 登录 Docker 注册表

某些空间将要求您登录 Hugging Face 的 Docker 注册表。为此，您需要提供：
- 您的 Hugging Face 用户名是 `username`
- 用户访问令牌为`password`。生成一个[here](https://huggingface.co/settings/tokens)。
