# 特色空间

Hugging Face 突出显示了某些空间，让您更轻松地发现社区构建的高质量演示和示例。

## 作者拥有的空间

模型、数据集和论文页面可以包含显示使用或引用该工件的空间的部分。星号图标标识作者拥有的空间，这些空间是由工件所有者创建的官方演示或示例。

在此处了解如何将空间链接到模型或数据集，以及如何在此处将其链接到论文。

## 本周空间
