# 安全

Hugging Face Hub 提供多种安全功能，以确保您的代码和数据的安全。除了为模型、数据集和空间提供[private repositories](./repositories-settings#private-repositories)之外，该中心还支持访问令牌、资源组、MFA、提交签名、恶意软件扫描等。

Hugging Face 符合 GDPR 规定。如果您需要合同或特定数据存储，我们建议您查看我们的[Team & Enterprise Support](https://huggingface.co/support)。 Hugging Face 还可以通过 [Enterprise Plan](https://huggingface.co/pricing) 提供业务伙伴附录或 GDPR 数据处理协议。 

Hugging Face 也是[SOC2 Type 2 certified](https://us.aicpa.org/interestareas/frc/assuranceadvisoryservices/aicpasoc2report.html)，这意味着我们为客户提供安全认证，并积极监控和修补任何安全漏洞。

对于任何其他安全问题，请随时向我们发送电子邮件：security@huggingface.co。
