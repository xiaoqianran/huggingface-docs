# 阿吉拉空间
Argilla 是一个免费的开源工具，用于构建和迭代人工智能数据。只需单击几下并启用 Hugging Face OAuth，即可将其部署在 Hub 上。这使得其他 HF 用户能够加入您的 Argilla 服务器来注释数据集，非常适合运行社区注释计划！

通过 Argilla，您可以：
- 配置数据集以收集人类反馈以及越来越多的问题（标签、NER、排名、评级、自由文本等）
- 使用模型输出/预测来评估它们或加快注释过程。
- UI 用户可以使用 Argilla 的搜索和语义相似性功能来探索、查找和标记最有趣/关键的子集。
- 从 Hugging Face Hub 中拉取和推送数据集以进行版本控制和模型训练。

在 Spaces 上开始使用 Argilla 的最佳位置是 [this guide](http://docs.argilla.io/latest/getting_started/quickstart/)。
