# 在 Data Studio 中编辑数据集

Data Studio 允许您直接在浏览器中编辑数据集值，然后将这些编辑提交回您的存储库 - 无需重新上传。

单元格编辑在以下情况下可用：

- 您拥有数据集存储库的**写入权限**。
- 所选分割由单个 `.csv`、`.tsv` 或 `.parquet` 文件支持。

## 进入编辑模式

单击 **切换编辑模式** 开始编辑当前拆分。

## 编辑和阶段更改

在编辑模式下，可编辑单元格显示编辑操作。
您可以编辑**字符串**、**数字**和**布尔**值（包括将值设置为`null`）。

编辑首先在本地进行，并显示为未保存的更改计数器，因此您可以在提交之前查看所有内容。

## 提交您的编辑

单击 **提交**，根据需要更新提交消息，然后确认。

> [!提示]
> 提交针对大文件进行了优化：Data Studio 计算精确编辑的字节范围并仅提交这些更改，而不是重写整个文件。通过 Xet 支持的分块和重复数据删除功能，可以有效地处理 Hub 上的存储和上传。

## 放弃分阶段编辑您可以随时退出编辑模式。如果您不想保留暂存的编辑，请在退出编辑模式之前放弃它们。
