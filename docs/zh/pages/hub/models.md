# 型号

Hugging Face Hub 包含许多 [variety of machine learning tasks](https://huggingface.co/tasks) 模型。模型存储在存储库中，因此它们受益于 Hugging Face Hub 上每个存储库所拥有的[all the features](./repositories)。此外，模型存储库具有使探索和使用模型尽可能简单的属性。这些文档将引导您了解在 Hub 上查找模型、上传模型以及充分利用 Model Hub 提供的一切所需了解的所有信息！
