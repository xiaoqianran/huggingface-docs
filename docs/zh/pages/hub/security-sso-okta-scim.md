# 如何使用 Okta 配置 SCIM

本指南介绍如何使用 SCIM 在 Okta 和您的 Hugging Face 组织之间设置 SCIM 用户和组配置。

> [!警告]
> 此功能是 Enterprise 和 Enterprise Plus 计划的一部分。

## 步骤 0：确认您的组织已正确设置

> [!注意]
> 仅当您在 Hugging Face 上设置托管用户时才需要执行此步骤。

在继续之前，请确保您的组织已转换为 Hugging Face **托管组织**。托管用户的 SCIM 配置仅适用于托管组织 - 如果您的组织尚未转换，请先联系您的 Hugging Face 客户团队，然后再继续执行以下步骤。

## 步骤 1：从 Hugging Face 获取 SCIM 配置1. 登录作为组织所有者的 Hugging Face 帐户（对于托管用户，请使用托管用户转换后提供的所有者帐户）。
2. 导航到 Hugging Face 上您组织的设置页面。
3. 转到 **SSO** 选项卡，然后单击 **SCIM** 子选项卡。
4. 复制 **SCIM 租户 URL**。您将需要它来进行 Okta 配置。
5. 单击**生成访问令牌**。将生成一个新的 SCIM 令牌。立即复制此令牌并安全存储，因为您将无法再次看到它。

    
    

## 第 2 步：输入管理员凭据1. 在 Okta 中，转到 **应用程序** 并选择您的 Hugging Face 应用程序。
2. 转到 **常规** 选项卡，然后单击应用程序设置上的 **编辑**
3. 对于配置选项，选择 **SCIM**，单击 **保存**
4. 转到“**配置**”选项卡，然后在“**设置**”下单击“**集成**”。
5. 输入 **SCIM 租户 URL** 作为 SCIM 连接器基本 URL。
6. 在用户的唯一标识符字段中输入 **userName**。
7. 为支持的配置操作选择所有必要的操作。
8. 为身份验证模式选择 **HTTP 标头**。
9. 输入您生成的**访问令牌**作为授权承载令牌。
10. 单击“**测试连接器配置**”以验证连接。
11. 保存您的更改。

## 步骤 3：重新配置 SAML

对于配置了 SAML SSO 的托管组织的 SCIM 调配，请更新现有 SAML 应用程序，使其标识符与 SCIM 一致：

1. 转至 **常规** 选项卡，然后单击 SAML 设置上的 **编辑**。
2. 点击**下一步**进入步骤2，**配置SAML**，并设置：
    - 姓名ID格式为`EmailAddress`
    - 应用程序用户名`Custom`，表达式为`user.getInternalProperty("id")`
3. 单击“**下一步**”，然后单击“**完成**”。

## 步骤 4：配置配置1. 在 **配置** 选项卡中，单击侧面导航栏中的 **到应用程序**。
2. 单击“**编辑**”并选中启用您需要的所有功能，即创建、更新、删除用户。
3. 单击底部的**保存**。

## 步骤 6：分配用户或组

1. 访问**分配**选项卡，单击**分配**
2. 单击“**分配给人员**”或“**分配给组**”
3. 找到需要分配的用户或组后，单击其名称旁边的**分配**
4. 在映射模式中，需要编辑用户名以符合以下规则。

> [!警告]
>
> 
> 用户名中仅接受常规字符和`-`。
> 禁止使用`--`（双破折号）。
> `-` 无法开始或结束名称。
> 不接受纯数字名称。
> 最小长度为 2，最大长度为 42。
> 用户名在您的组织内必须是唯一的。
>5. 向下滚动并单击“**保存并返回**”
6. 单击**完成**
7. 确认您的 Hugging Face 组织中的用户或组已按预期创建、更新或停用。

## 步骤 7：通过 SCIM 将 Okta Groups 推送至 Hugging Face

在将组链接到 Hugging Face 资源组之前，您需要使用 **推送组** 选项卡将 Okta 组推送到 Hugging Face。这与步骤 6 中将用户分配给应用程序不同。

> [!警告]
> Okta 不支持使用同一组进行应用程序分配（步骤 6）和组推送。使用专门的小组进行推送——将推送组与任务组分开。1. 在 Okta 管理控制台中，转到 **应用程序** 并选择您的 Hugging Face 应用程序。
2. 单击“**推送组**”选项卡。
3. 单击“**+ 推送组**”并选择“**按名称查找组**”。
4. 搜索要推送的 Okta 组并从结果中选择它。
5. 选择如何处理抱脸中的群组：
    - **创建组**：在您的 Hugging Face 组织中创建一个新的 SCIM 组。
    - **链接组**：链接到您的 Hugging Face 组织中已有的现有组。
6. 单击“**保存**”。要推送其他组，请单击“**保存并添加另一个**”并重复。

推送后，该组将显示在 Hugging Face 组织设置中的 **SCIM 组** 下（SSO → SCIM 选项卡）。您在 Okta 中对群组所做的任何成员资格更改都会自动同步到 Hugging Face。

## 步骤 8：将 SCIM 组链接到 Hugging Face 资源组

从 Okta 配置您的组后，您可以将它们链接到 Hugging Face 资源组以大规模管理权限。这允许 SCIM 组的所有成员自动接收资源集合的特定角色（例如读取或写入）。> [!注意]
> 在链接之前，请确保您要链接的资源组是**空**（没有现有成员）并且**未**启用自动加入。这两个条件都是必需的 - 否则链接将失败。

1. 在 Hugging Face 组织设置中，导航到 **SSO** -> **SCIM** 选项卡。您将在 **SCIM 组** 下看到您配置的组的列表。
2. 找到您要配置的组，然后单击其行中的 **链接资源组**。
3. 将出现一个对话框。单击“**链接资源组**”。
4. 从下拉菜单中，选择要链接的 **资源组** 以及要授予 SCIM 组成员的 **角色分配**。
5. 单击 **链接到 SCIM 组** 并保存映射。

链接后，资源组将变为 **SCIM 管理**：SCIM 组中已有的任何成员都会立即添加到资源组（回填），并且 Okta 中所有未来的成员资格更改都会自动反映。通过 Hub UI 或 API 对资源组进行手动成员资格编辑将被阻止。
